THREE-LAYER ARCHITECTURE

Hybrid Combat Stack

DART operates as a three-layer hybrid system — each layer handles a different aspect of the combat experience.

LAYER 01
📡
RF Lock-On Layer
Target discovery, directional hot/cold feedback, and proximity estimation via RSSI. Team and player beaconing for arena-wide identification.
ESP-NOW @ 2.4 GHz ISM band
Directional patch antenna array
Multi-antenna RSSI comparison
Player ID & team beaconing
LAYER 02
🔴
IR Optical Hit Layer
Actual hit confirmation via line-of-sight IR tagging. Encoded packets with CRC validation ensure only legitimate hits are scored.
940nm IR LED + 38 kHz carrier
Encoded packet: ID, team, damage, CRC
360° multi-sensor ring
Cooldown & team validation
LAYER 03
🎮
Flight & Pilot Feedback
LEDs, buzzer, vibration on the drone. CRSF telemetry to pilot radio for haptic hit notification and game state display.
NeoPixel LED damage indicators
CRSF/SBUS telemetry passthrough
Haptic pilot feedback via radio
AUX channel injection (DART Bridge)
MODULAR SYSTEM

DART Product Modules

Each module is independent, swappable, and designed to be developed and tested in isolation before integration.

🧠
DART CORE
Main onboard MCU. Game logic, HP tracking, state machine, hit validation, and inter-module communication.
📡
DART SEEKER
Directional RF receiver with patch antenna array. RSSI-based lock-on and direction finding.
📶
DART BEACON
RF identity transmitter. Broadcasts player ID, team, and arena sync data via ESP-NOW.
🔌
DART BRIDGE
RC receiver-to-FC interposer. CRSF/SBUS passive sniffer with optional AUX channel injection.
💥
DART TAGGER
IR weapon emitter. 940nm modulated LED with encoded packet transmission for scoring.
🛡️
DART SENSOR RING
Multi-direction IR hit sensor array. 4-6 receivers for 360° coverage with directional hit detection.
📳
DART HAPTIC
Pilot feedback module. Vibration, buzzer, and LED mapped to lock strength and hit events.
🏟️
DART ARENA
Game rules, scoring, match management. HP, teams, respawn timers, kill count, and leaderboard.
WHAT MAKES DART DIFFERENT

Not Toy Laser Tag

DART is a modular FPV drone combat platform. Built for real pilots, real drones, and real competitive gameplay.

🎯

Dual-Layer Confirmation

RF for lock-on, IR for hit. No false positives from reflections or multipath.

🔗

Flight Controller Integration

CRSF/SBUS interposer injects game events directly into the FC via AUX channels.

📳

Pilot Haptic Feedback

Feel the lock, feel the hit. Vibration mapped to signal strength — eyes on FPV, hands on sticks.

🔓

Fail-Safe Architecture

Hardware bypass on DART Bridge. If MCU fails, RC signal passes through uninterrupted.

DEVELOPMENT PHASES

Build Roadmap

Phased hardware prototyping — validate RF behavior before adding complexity. Each phase builds on the previous.

PHASE 01
ESP-NOW Basic Beacon
TX sends packet every 100ms. RX prints RSSI in Serial Monitor. Verify signal changes as you move TX closer/farther.
● READY TO BUILD
PHASE 02
OLED Display Integration
Real-time RSSI, average RSSI, packet loss, lock status, and signal level bar on 0.96" I2C OLED.
NEXT
PHASE 03
Buzzer & Vibration Feedback
Hot/cold feedback — faster beep and stronger vibration as signal strengthens. Eyes-closed locate test.
NEXT
PHASE 04
Antenna Comparison Testing
Whip vs patch vs panel vs Yagi. RSSI at 0°, 30°, 60°, 90°, 180° for each antenna. Measure real directionality.
NEXT
PHASE 05-09
Direction Finding → IR → DART Bridge
Two-direction receiver, drone frame mockup, flight-safe power, IR hit detection system, and CRSF passive sniffer.
